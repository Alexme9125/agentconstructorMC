# PrintCore Forge mod

Server-side 1.20.1 Forge mod. Shares `logic/src/main/java` as extra sources.

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
./gradlew build
```

Optional: install WorldEdit 7.2.15 next to this jar so operators can wand-edit; PrintCore paste does not call WorldEdit commands.
